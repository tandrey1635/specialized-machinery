#  Сайт «Аренда спецтехники»
Многостраничный адаптивный веб-сайт (5 стр) для компании по аренде спецтехники. Проект реализован на чистом HTML5/SASS и JavaScript с семантической версткой, слайдерами, табами, таймером обратного отсчета, аккордеонами, модальными окнами и интерактивной картой.


## 🛠 Технологический стек

### Frontend
- **HTML5** — семантическая верстка, БЭМ-методология
- **SASS/SCSS** — модульная структура, сброс стилей, переменные, медиа-запросы
- **JavaScript** — работа с DOM, обработка событий


## 🎯 Ключевые функции

### UI/UX элементы
- Адаптивное бургер-меню для мобильных устройств
- Плавная навигация по странице
- Темная тема с сохранением выбора в localStorage
- Адаптивные карусели спецтехники и отзывов (главный слайдер с автоматической сменой слайдов)
- Таймеры акций и специальных предложений
- Табы каталога спецтехники с фильтрацией по категориям
- Кнопка «Показать еще» для постепенной загрузки карточек каталога
- Модальное окно аренды с автозаполнением данных выбранной техники
- Аккордеоны для полезной информации и кнопкой «Развернуть все»
- Анимированные счетчики статистики компании
- Интерактивные карты


## 🔧 Технические особенности

### Адаптивность
- Адаптивный дизайн
- Медиа-запросы
- Кросс-браузерная совместимость


**Проект демонстрирует навыки верстки многостраничного сайта с адаптивом и уверенное владение чистым JavaScript с множеством интерактивных элементов, готового к интеграции с бекендом.**
